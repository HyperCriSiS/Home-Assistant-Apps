Set up Cloudflare

In the Cloudflared App (local tunnel) add this entry under additional_hosts. With a remote-managed tunnel (tunnel_token), create the same public hostname and service in the Cloudflare dashboard instead.

–
Set up Tailscale

Devices in your tailnet reach MCPHub directly at http://<Home Assistant Tailscale name>:3001/mcp.

For public access through Funnel, run this once in the Tailscale App container, for example from the Advanced SSH & Web Terminal App with protection mode disabled (docker exec addon_a0d7b954_tailscale …). Port 8443 avoids a conflict when Home Assistant itself is shared on 443.

–
Connect MCP clients

Create a key in MCPHub under Keys, then use Copy client config on a server or group. MCPHub fills in the external address configured for this App, so the copied configuration works from outside Home Assistant.

The address check sends one request without credentials and expects MCPHub's gateway to answer with 401. Diagnostics and logs load when expanded and do not intentionally expose credentials.
